Getting your list in

Use List view in LCR. It prints the section name above every calling, which is what lets the board build your organizations and color-banded groups without any hand sorting. Select the list, copy it, and paste it into Import → Calling list. A preview tells you what it found before you commit.

Other LCR layouts import too, just with less structure — you may need Edit layout afterward to tidy the columns. Paste a membership list under Member list to add people who hold no calling yet.

Marking who's available

Tick the box next to anyone the bishopric would consider right now. Mark shown ticks everyone currently listed, and Clear unticks them. Turn on Available only to narrow the list to those people while you work.

To drop someone from the list, hover their row and click the ✕ on the right. Useful for stray entries an import picked up by mistake.

Moving people

  • Drag a name onto a calling, or click the name and then click the calling. Clicking is easier when you're driving a projector.
  • Dragging someone out of one calling and onto another swaps the two.
  • Drag a name back to this list to leave their calling open.
  • ✕ unassigns, ↺ restores the current person, and Undo (Ctrl+Z) reverses the last move.

Weighing several names

When more than one person could fill a calling, put them all on it and decide later. Drop a second name from this list onto a calling that already has someone and both become candidates; keep dropping to add more. The calling turns amber and reads "Considering 3".

Each candidate gets a ✓ to call them, which clears the others in one click, and an ✕ to take just that person off. The + on any calling starts the same thing from the member list. Nothing is settled until you click a ✓, so the Summary lists these apart as "Still deciding".

Finding people fast

The box above the member list searches names only; the one in the top bar searches the board. Click an Open position, either on the board or in the Open tab, and it jumps to that calling and drops the cursor into the member search — type a few letters, click the name, done. Open only at the top hides every calling that already has someone, which is the quickest way to work down what's left.

Reading the board

  • Green means a proposed call.
  • Red struck-through means someone is being released.
  • Amber with a dashed edge means names are still being weighed.
  • A red dashed outline means the position is open.
  • Each organization header counts its open, deciding, and changed callings.

Fitting it on screen

Use the organization chips along the top to show or hide groups — All toggles every one of them at once. Collapse all shuts every organization down to its header, and turns into Expand all to open them again; ▾ on a single header does one at a time. Then Changes only for just the moves, Open only for just the gaps, Compact to fit more, and the top search to find a person or calling.

An organization with 14 or more callings stops being a tall narrow column and spans the whole board instead, with its groups flowing across it — a long Primary or Relief Society reads in a couple of screens rather than endless scrolling. Wide organizations sit above the rest. In Edit layout, the arrows button on any organization header overrides this either way, and the choice is remembered.

Finishing a meeting

Draft and Current switch between what you're proposing and what's in place today. Summary lists every release and call by organization and can copy them as text.

Calls rarely all happen at once, so each one is ticked off on its own. Once a call has been extended, sustained, and recorded in LCR, click its ✓ — on the calling itself, or beside it in Summary. That calling becomes current, drops off the list of changes, and a newly called person's time in calling starts from that day. Mark all as done in Summary still does the whole list at once, and leaves anything still being decided alone.

Keeping it private

Everything stays in this browser on this computer. Nothing is uploaded. Hide names (or the H key) blurs every name instantly if someone walks in. Save backup writes a file that does contain names, so store it somewhere private, and use Clear everything in Import when the laptop is no longer the right place for it.

Groups inside a column

A long organization can be split into color-banded groups — a presidency, the classes, the teachers. A List view import builds these from LCR's own section names; other pastes fall back to headings, then to the calling names.

In Edit layout, a band header gains ✎ to rename the group, ◑ to step through seven colors, and ✕ to remove the banding while keeping the callings. To put one calling in a different group, use its ⇄ button and pick the organization, then the group. Callings with no group collect at the bottom of the column, below the bands.

Fixing the layout

Turn on Edit layout and each calling gets three buttons: ✎ renames it, ⇄ moves it to another organization, and 🗑 deletes it. Organization headers gain rename, reorder, and delete. Moving a calling keeps whoever is in it, so use ⇄ when the import files something under the wrong group — anything it can't place lands in Other Callings.

Time in calling

When the import carries a sustained date, each filled calling shows how long that person has served — "3 yr 2 mo in calling" under their name, and alongside anyone being released. Hover it for the exact date. LCR's List view supplies these dates; a paste without them simply shows nothing.

Checking the data

Reports whether this browser is actually storing your board, anything repaired when it loaded, and things worth a second look — a shortlist left with one name, someone holding three or more callings, repeated titles that might mean a double import.

If a red Not saving button ever appears in the top bar, this browser has stopped storing data. Everything on screen still works, but nothing is being kept. Save a backup straight away.

Asking for a change

Describe what would make the planner more useful. Open an issue on GitHub hands it to the project's issue list with everything filled in — what you asked for, which revision you are on, and the size of your board — and you press Submit there. That needs a GitHub account, and the issue is a public page. Copy instead gives you the same text to send any way you like. The same button sits at the top of the revision history.

The page itself sends nothing and stores nothing about you beyond the name you type, which it remembers for next time. Leave member names out of a request either way.

Which version is this

Click the revision pill in the top left for the history of what changed. The number is also stamped into backup filenames and copied summaries, so you can tell which build someone is running.
